# Network Infrastructure Labs

A collection of hands-on networking labs developed using Cisco Packet Tracer.

This repository documents practical implementations of network infrastructure concepts, including router configuration, IP addressing, dynamic routing, SNMP-based network monitoring, and network connectivity verification.

## Tools & Technologies

- Cisco Packet Tracer
- Cisco IOS CLI
- IPv4 Addressing
- RIPv2
- SNMPv1 & MIB Browser
- ICMP & Packet Tracer Simulation Mode
- Network Troubleshooting
