# Network Infrastructure Labs

A collection of hands-on networking labs implemented using Cisco Packet Tracer.

This repository documents practical work in network infrastructure, including router configuration, IPv4 addressing, dynamic routing, SNMP-based monitoring, network services, inter-LAN connectivity, connectivity verification, and troubleshooting.

## Tools & Technologies

- Cisco Packet Tracer
- Cisco IOS CLI
- IPv4 Addressing & Subnetting
- Static IPv4 Configuration & Default Gateways
- RIPv2
- SNMPv1 & MIB Browser
- DHCP & DNS
- HTTP & HTTPS
- SMTP & POP3
- ICMP & Packet Tracer Simulation Mode
- Network Troubleshooting

## Completed Labs

| Lab | Description | Focus | Status |
|---|---|---|---|
| [Lab 01 — Dynamic Routing Using RIPv2](./Lab-01/) | Configure dynamic routing between interconnected networks | IPv4 addressing, RIPv2, route verification, end-to-end connectivity | Completed |
| [Lab 02 — SNMP Network Monitoring](./Lab-02/) | Configure and test SNMP-based network monitoring | SNMPv1, MIB Browser, device monitoring, SNMP GET | Completed |
| [Lab 03 — Network Services: DNS, DHCP, HTTP & Email](./Lab-03/) | Configure and verify essential network services within a LAN | DHCP address assignment, DNS resolution, HTTP access, SMTP/POP3 email communication | Completed |
| [Lab 04 — Inter-LAN Connectivity](./Lab-04/) | Connect two IPv4 LANs through a single router and verify bidirectional communication | Static IPv4 addressing, default gateways, router interfaces, ICMP ping verification | Completed |
